
# LangChain & Agentic AI Lab

Hands-on exploration of Large Language Models (LLMs), LangChain, LangGraph, and AI agents through practical exercises and experiments.

## Overview

This repository documents my learning journey in LLM application development and agentic AI, combining theoretical concepts with hands-on Python implementations.

## Topics Covered

- Large Language Models (LLMs)
- Prompt engineering and chat models
- LangChain and LangGraph
- Tool calling and structured outputs
- Retrieval-Augmented Generation (RAG)
- AI agents and agentic workflows
- Conversational memory and state management
- LLM application evaluation and tracing

## Tech Stack

**Language:** Python

**Frameworks:** LangChain, LangGraph

**Models & APIs:** OpenAI API

**Observability:** LangSmith

**Environment:** Jupyter Notebook, Git, GitHub

## Repository Structure

The repository is organized into learning modules containing notebooks, examples, and practical experiments.
